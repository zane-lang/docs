# Zane docs

Documentation pages for the Zane website, which the
[`website`](https://github.com/zane-lang/website) repository includes as a
submodule. So far it holds an early description of the `zane` command.

> **Status:** not maintained at the moment (last changed in March 2026) and
> behind the current language and tools. **Newcomers can skip this
> repository.** Start at [`zane-lang/zane`](https://github.com/zane-lang/zane);
> the language is described in the [specification](https://github.com/zane-lang/spec),
> and the `zane` command in
> [`docs/design/cli.md`](https://github.com/zane-lang/zane/blob/main/docs/design/cli.md).
